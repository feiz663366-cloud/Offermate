How to use this page (for reviewers):
This is a static reproduction of a typical Chinese campus-recruitment application form. Its labels are in Chinese on purpose — the extension matches field labels by meaning, and real application forms are in Chinese. You do not need to read Chinese to verify the result: click the Offermate toolbar icon, press “一键填写当前页面” (the large blue button), and watch every field below get filled in one by one, followed by a result panel listing each written value.
The extension never clicks the submit button — the button at the bottom is only there so you can confirm it stays untouched. This page sends nothing anywhere.
